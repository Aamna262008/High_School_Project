# Study Deadline Checker

A small command-line program that reads homework deadlines from a CSV file
and shows which tasks are overdue or coming up in the next 7 days.

## How to run

```
python study_deadline_checker.py
```

## CSV format

Tasks are stored in `tasks.csv` with four columns:

```
subject,task,due_date,completed
Math,Algebra practice,2026-08-25,no
```

Dates use the YYYY-MM-DD format.
