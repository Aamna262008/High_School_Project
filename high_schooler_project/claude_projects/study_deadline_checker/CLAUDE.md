# Project rules

- This is a beginner Python project: the Study Deadline Checker.
- Use only the Python standard library (csv, datetime) — no Flask, pandas, databases, APIs, or GUI frameworks.
- Do not use classes unless they are clearly necessary.
- Prefer small functions with simple names: load_tasks, show_report, add_task, main.
- Task data lives in tasks.csv with columns: subject,task,due_date,completed (dates in YYYY-MM-DD format).
- Before editing, explain the planned change briefly.
- After a change, run the relevant program or tests.
- Do not replace working beginner code with advanced abstractions.
- When explaining an error, explain it in beginner-friendly language.
- Work one small step at a time — never build the whole project in one prompt.
- Do not modify the other projects in this repository (student marks manager, movie ticket calculator, expense tracker).
