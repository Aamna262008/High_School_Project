# Project rules

- This is a beginner Python project: the Simple Expense Tracker.
- Use only the Python standard library (csv, datetime).
- Keep the program small and readable.
- Prefer functions, loops, dictionaries, and simple conditions.
- Do not use classes unless I specifically ask for them.
- Do not add a database, GUI, web framework, or external package.
- Expense data lives in expenses.csv with columns: date,category,amount,description (dates in YYYY-MM-DD format).
- Categories are: Food, Transport, Study, Entertainment, Other.
- Planned functions: load_expenses, add_expense, calculate_summary, create_report, main.
- Running `python expense_tracker.py --report` must create spending_report.txt without opening the menu.
- Before editing, explain the planned change briefly.
- Implement one function at a time when possible.
- After a change, run the relevant program or tests.
- Explain errors in beginner-friendly language.
- Never put real private financial data into this repository — sample data only.
